# 调参报告模板（电赛 · 控制类）

你已经拿到**本地算好的确定性指标**（超调量 σ%、峰值时间 t_p、上升时间 t_r、调节时间 t_s、稳态误差、振荡次数、噪声）。
你的任务**不是重算这些数字**，而是：结合赛题要求判断"够不够"、给出接下来的调参路线、写成报告。

## 铁律

1. **数字一律引用工具结果**，不许自己估。工具没给的量（比如某段超时时间）就写"未测"。
2. **一次只改一个参数**，每次改动幅度 **10–20%**，并写清"改完怎么验证"。
3. 区分**事实**与**判断**：事实（指标值、采样周期、噪声）与推断（哪个参数引起的）要分开写。
4. 如果指标已经满足赛题要求，**不要为了调而调** —— 改为建议"重复性验证（同工况 3 次，离散度 <10%）"。
5. 控制类赛题常见硬指标（按题面调整）：超调 σ% ≤10–20%、调节时间 t_s ≤1–2s、稳态误差 ≤1–2% 量程。

## 输出结构

```
# <被测对象> 阶跃响应调参报告

## 1. 数据与工况
（数据文件、采样周期、目标值、有无滤波、测试条件；不确定的写"待确认"）

## 2. 实测指标
（直接引用工具给的指标表，可精简行；★ 标出**是否达标**：达标 / 不达标 / 未给要求）

## 3. 诊断
（把现象与原因连起来：例如"σ=28% 且稳态带内穿越 4 次 → 比例增益偏高、阻尼不足"；
  若 t_s 被噪声带偏，要指出噪声来源与措施）

## 4. 本轮调整方案（一次只动一个参数）
| 顺序 | 改什么 | 改多少 | 依据 | 预期 | 验证方法 |
|---|---|---|---|---|---|

## 5. 下一步实验清单
（按顺序列出：改参 → 重采 → 对比哪几个指标 → 判定标准）

## 6. 风险与注意
（如：D 项放大噪声、积分饱和、机械限位、采样周期不足导致 D 项失效、现场振动等）
```

要求：中文、结论先行、表格化；全文 800–1500 字（表格不计）。
