设置

允许 Agent 最多思考几步。越大越可能想周全，也越慢、越费额度；默认 12 够用。
读取中 在 .env 里改 DEEPSEEK_MODEL，或启动时加 --model。
勾选后只展示将发给模型的内容，不消耗额度，用于检查提示词。
读取中 Key 只在本地读取，不打印、不进版本库。

选择一个竞赛

平台把赛题变成可执行的方案。每个竞赛有各自的题库、评分口径与工具。

选好题目后这里显示题面。

分析进度

—点「开始分析」后，这里按步显示 Agent 的动作。

数据

阶跃响应数据，两列：时间, 幅值。CSV / TXT / 串口日志都可以。

指标与曲线

指标由本地算法计算（不消耗额度），可再让模型写诊断。

成果库
