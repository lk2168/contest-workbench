fix(web): 题目改成「年份/批次 + 题目」两级选择 + 题面预览（解决分析错年份）

问题（用户发现）：题库里 2021/2023/2024/2025/2026 都有 H 题，网页端只有一个
「题号/关键词」输入框，填 H 根本不知道要分析哪一年 —— 实际会按"最新年份"猜。

后端：
- shiti.py 新增 list_shiti_structured()（年份/批次、题号、题名、精确文件名、字数、label）
  与 _find_exact()（按文件名精确查找）
- read_shiti 新增 file 参数（精确文件名优先），并在多命中时提示其它年份
- 新接口 GET /api/shiti-list（结构化清单 + 年份列表）
- 新接口 GET /api/shiti-detail?file=...（按精确文件名读题面 + 元信息）
- /api/analyze 改为接收 file + label：任务描述里写明「2026-省赛 · H 题 · 车名」，
  并要求模型用 read_shiti(file=...) 精确定位、报告文件名带年份

前端：
- 第一行：竞赛分区 + 年份/批次；第二行：题目 + 最多步数（原排版会把"最多步数"挤到孤行）
- 新增题面预览面板（默认预览 1800 字，可点「展开题面全文」），
  预览里带年份/批次标题、字数、以及"其它年份也有 H 题：2025-国赛，2024-省赛"的提示
- 分析按钮改为「开始分析这题」，运行状态显示当前题目
