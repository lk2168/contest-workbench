feat(v0.2): 调参助手 + 竞赛分区抽象（平台化第一步）

调参助手（diansai_agent/tools/tuning.py）：
- 解析 CSV/TXT/串口日志（取末两列，兼容时间戳前缀），编码自动嗅探
- 确定性指标：超调量 / 峰值时间 / 上升时间(10-90%) / 调节时间(±2%,±5%) / 稳态误差 / 振荡次数 / 噪声
- 规则化 PID 建议（改哪个 / 改多少 / 预期 / 怎么验证），纯函数、可重复
- matplotlib 出曲线图（中文字体），报告落 md + docx
- 新 CLI：python cli.py tune <数据> [--target X] [--no-llm]

竞赛分区（diansai_agent/domains.py）：
- Domain = 题库目录 + 提示词 + 报告模板 + 该分区启用的工具
- 已实现 diansai；登记 mathmodel / itcup / startup 三个规划中分区
- 题库改为 data/题库/<分区>/<年份>/；CLI 加 --domain / --domains
- 新增分区只需：题库 + 提示词 + 一条 Domain 登记（不动核心代码）

测试（新增 20 项；过程中修掉 4 个真 bug）：

- bug2 起始点检测阈值(0.1%幅值)低于噪声 → t_start 误判成 0（真实 0.3s）
      改为噪声自适应阈值 max(0.3%幅值, 3σ)
- bug3 在带噪声原始信号上数穿越 → 振荡数虚高到 100、t_s 被拖到 3.7s
      改为平滑后判定 + 要求摆动幅度超过 0.5 倍稳态带才算真振荡
- bug4 np.convolve(mode='same') 边缘补零 → 稳态段被误判偏出带外，t_s 算不出(None)
- tests/test_offline.py：19 → 27 项（补分区与提示词断言）
