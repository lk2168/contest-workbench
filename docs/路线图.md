## 计划中

| 版本 | 内容 | 验收标准 |
|---|---|---|
| **v0.5** | **接入第 2 个竞赛分区**（智能汽车最省事：控制类同源，调参助手可直接复用） | `python cli.py --domain <分区> analyze <题号>` 能出可用方案；网页端页签**自动**只显示该分区具备的能力（不用改前端） |
| v0.6 | 评测框架：10 条真题任务 → 自动打分 → 回归报告 | 能看出"改提示词前后"分数变化；分数由确定性规则算，不靠模型自评 |
| v0.7 | **发布 exe 到 GitHub Releases + 首次运行更友好** | 陌生人从 Releases 下载 → 双击 → 填 Key → 出报告，全程不需要命令行 |
| v0.8 | 多用户 / 云端部署（账号、历史记录、分享链接） | 一条链接能分享一份报告，队友打开即看 |

> ⚠️ v0.4 的 exe **只在本机实测过**（Windows 11 + Python 3.13 打包）。
> 真要让陌生人用，还需要：① 传到 Releases ② 在一台**没装 Python** 的干净机器上验证 ③ 首启动 46 MB 要解包，冷启动约 5–10 秒（要有提示，别让用户以为卡死）。

## 长期候选（未排期）

- 赛题 PDF 里的**示意图/表格**抽取（OCR 或转图）—— 对"看图搭方案"影响最大
- 串口实时采集（`pyserial`）→ 边调边看曲线
- 深色模式 / 移动端体验优化
- DSH 插件薄壳（借用宿主桌面端，几乎零打包成本）

## 判断原则（写在最前面，免得跑偏）

1. **能用确定性算法算的，不交给模型猜** —— 模型负责判断与写作，指标由代码算并配测试
2. **零构建** —— 不引前端框架、不加打包步骤（"队友零安装"是最大优势，别为了好看牺牲它）
3. **每加一个功能，先问"验收标准是什么"** —— 说不清就说明还没想清楚
