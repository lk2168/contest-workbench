## 这一版回答两个问题：「出了方案就改不了」和「为什么只能接 DeepSeek」

### 新增：追问（分析完可以接着问）

以前 Agent 跑完就把对话丢了 —— 报告出来后想问"这条要求我怎么满足""器件能换成 XX 吗"，
模型已经不记得刚才分析的是哪道题。现在分析结果下面多了一个**追问框**：

- **模型记得上下文**：会把「本次任务 + 报告 + 之前的问答」一起带上（只带人话部分，
  中间的工具调用不重放，省 token 也不容易出错）
- **追问这一轮仍然带工具**：它可以自己回去**重读题面、检索赛区答疑**，而不是只凭记忆回答
- 单次分析最多留 12 轮问答、6 小时不用自动回收（本机内存里，不落盘）

### 新增：支持 8 家模型供应商（不再只有 DeepSeek）

代码本来就是通用 OpenAI 兼容格式，之前"只支持 DeepSeek"是**配置层的写死**，不是能力限制。现在设置里可以选：

| 供应商 | 说明 |
|---|---|
| **DeepSeek（官方）** | 默认，本机实测 `deepseek-flash` / `deepseek-v4-pro` |
| 月之暗面 Kimi | 填 Key 即可 |
| 阿里通义千问 | 用 DashScope 兼容模式地址 |
| 智谱 GLM | 填 Key 即可 |
| 硅基流动 SiliconFlow | 一个 Key 用多家开源模型，适合做对比 |
| OpenAI | 国内直连通常需要代理 |
| **本地 Ollama** | **免费、数据不出本机**（`ollama pull` 后直接选） |
| 自定义 | 任何 OpenAI 兼容接口：自建、代理、公司内网 |

- **不预设模型名**（各平台改名很频繁，写死很快过期）→ 设置里点「**拉取可用模型**」直接问对方要真实列表
- **接口地址可改**：自建/代理/换区域都行，程序会自己拼 `/chat/completions`
- 本地 Ollama **不需要 Key**（随便填 `ollama`）

### 修复：分析报告在网页端渲染不出来

`answer` 事件只带了 `text` 字段，而前端读的是 `answer` → 报告生成了但页面上不显示
（之前一直靠"成果库里的文件"看，所以没暴露）。现在两个字段都发，前端也做了兼容。

> 这个 bug 是**新写的追问测试**抓出来的：它断言"分析流里必须有回答"，一跑就红了。

### 质量

- **六套测试 152 项**全部通过（工具链 27 + 调参 20 + 网页端 70 + 启动器 5 + 前端运行时 8 + 追问与供应商 24）
- 追问的上下文是否正确，用**假 LLM** 离线验证（断言第二轮请求里确实带了上一轮报告），不花钱
- CI 三个环境：ubuntu 3.10 / ubuntu 3.13 / windows 3.13

### 怎么用

1. 双击 `contest-workbench.exe`（自己的桌面窗口，不需要装 Python）
2. 右上角「设置」→ 选供应商 → 填 Key → 点「拉取可用模型」→ 选一个模型 → 保存
   （用本地 Ollama 的话：先 `ollama pull qwen2.5:7b`，供应商选 Ollama，Key 填 `ollama`）
3. 首页进电赛 → 选题目 → 开始分析 → 出报告后在下面**继续追问**

**已知限制**：不含题库（版权原因，需自己准备，界面里有引导）；
只在 Windows 11 上打包实测；追问的上下文存在内存里，重启程序即清空。
