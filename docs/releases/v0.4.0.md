## 这个版本能"双击就用"了

下载下面那个 `diansai-agent.exe`（v0.4.0 时的文件名），**双击**即可（Windows，**不需要装 Python**）。会自动起一个本地服务并打开浏览器。

### 三步用起来

1. **双击** `diansai-agent.exe`（首次启动要解包 46 MB，约 **5–10 秒**，属正常，请稍等）
2. 浏览器打开后，点右上角「**设置**」→ 粘贴你的 **DeepSeek API Key** → 保存 → 点「**测试连接**」验证
   （Key 在 <https://platform.deepseek.com/api_keys> 申请；只存在你自己电脑上，不上传）
3. 首页点「**进入电赛**」→ 选年份和题目 → 点「**开始分析**」

想不花钱先看效果：设置里勾上「**只看提示词（不调用模型）**」，再点开始分析。

### 新增

- **打包成单文件 exe**：46.1 MB，双击即用，不要求用户装 Python
- **网页端可直接填 API Key**：不用再手改 `.env`（设置里保存 + 测试连接；界面上只回显打码后的 Key）
- **一键自检**：设置里「运行自检」逐项检查 Key / 提示词 / 界面资源 / 输出目录 / Word 转换 / 计算库 / 题库，出问题先跑它
- **修复一个只有打包后才会暴露的坑**：Word 转换原来用子进程调用（冻结后 `sys.executable` 就是 exe 自己，
  会把整个程序再启动一遍），已改为进程内调用

### 已知限制（请先看清楚再下载）

- **不含题库**（赛题原文与评分标准的版权不属于本项目）：exe 同目录放 `data/题库/<分区>/` 即可被读到，
  或用源码里的 `scripts/fetch_history.py` 重建历年题库
- **需要你自己的 DeepSeek API Key**（会产生费用，本项目只统计 token 不代付）
- 只在 **Windows 11 + Python 3.13** 上打包并实测过；没有在"完全干净的机器"上验证
- 调参助手面向**控制类**（阶跃响应）；电源/测量/信号类题目还没有专属工具
