## 改名字了：diansai-agent → contest-workbench

项目已经是**多竞赛平台**（电赛已实现，数学建模 / IT 类 / 创新创业在规划中），
再叫「电赛 Agent」就把身份锁死在单个竞赛上了。所以这一版改了名：

| 项目 | 旧 | 新 |
|---|---|---|
| GitHub 仓库 | `diansai-agent` | **`contest-workbench`** |
| 界面显示名 | 竞赛 Agent 平台 | **大学生竞赛工作台** |
| Python 包 | `diansai_agent` | `contest_workbench` |
| exe | `diansai-agent.exe` | `contest-workbench.exe` |
| 环境变量 | `DIANSAI_*` | `CONTEST_*`（**旧名仍兼容**） |

**旧链接不会失效**：GitHub 对改名的仓库保留自动跳转，原来的地址会 302 到新地址。
`pip`/import 写 `diansai_agent` 的老代码才需要改（本项目自己的代码已全部更新）。

### 两个"会把人搞丢"的点，已处理

1. **已保存的 API Key 不会丢**：用户配置目录从 `~/.diansai-agent` 换成 `~/.contest-workbench`，
   首次运行会**自动把旧目录里的配置复制过来**（不覆盖新文件）
2. **旧环境变量仍可用**：`DIANSAI_KB` / `DIANSAI_DOMAIN` 等会被继续读取（新的 `CONTEST_*` 优先）

## 这个版本怎么用

下载 `contest-workbench.exe`，**双击**即可（Windows，**不需要装 Python**）。

1. **双击** exe（首次启动要解包 46 MB，约 **5–10 秒**，属正常）
2. 浏览器打开后，点右上角「**设置**」→ 粘贴你的 **DeepSeek API Key** → 保存 → 点「**测试连接**」
   （Key 在 <https://platform.deepseek.com/api_keys> 申请；只存在你自己电脑上）
3. 首页点「进入电赛」→ 选年份和题目 → 点「**开始分析**」

想不花钱先看效果：设置里勾上「**只看提示词（不调用模型）**」。

### 出问题先点「运行自检」

设置抽屉里有「运行自检」，会逐项告诉你哪里不对：Key / 提示词 / 界面资源 / 输出目录 /
Word 转换 / 示例数据 / 计算库 / 题库。

### 已知限制（下载前请看清楚）

- **不含题库**（赛题原文与评分标准的版权不属于本项目）：exe 同目录放 `data/题库/<分区>/` 即可被读到；
  或用源码里的 `scripts/fetch_history.py` 重建历年题库
- **需要你自己的 DeepSeek API Key**（会产生费用；本项目只统计 token，不代付）
- 只在 **Windows 11** 上打包并实测；没有在"完全干净的机器"上验证过
- 调参助手面向**控制类**（阶跃响应）；电源/测量/信号类题目还没有专属工具
