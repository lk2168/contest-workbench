redesign(web): 按设计规范重做视觉（设计 token + 工艺清单），并把经验固化

用户反馈前端「太粗制滥造」，要求：搜索怎么做才好看 → 做出更高级的首页与各界面 → 固化成经验 → 其他模块同风格。

先检索（按项目规矩「先找现成的」）：
- svssdeva/agentic-skills · interface-design（★ 本次主要依据）："看起来贵"的工艺清单
- curiositech/windags-skills · swiss-modern：实现顺序（token → 布局 → 字阶 → 组件 → 最后才谈强调色/动效）
- argyleink/open-props（★5.5k）：用 CSS 自定义属性做设计 token，零构建
- Ilm-Alan/frontend-design（已装为 skill）：内容纪律（禁伪造数据/禁填充标签/禁 unicode 字符当图标）
- 评估后不用 DaisyUI（★42k）/ shadcn（★20k）：需要 Tailwind/React 构建，会破坏"零安装、离线可用"

设计 token（写进 <style> 顶部，其他模块复用，不在组件里写死）：
- 中性阶 g25–g900（冷灰，一根色相只变明度）+ 唯一强调色 b600 #2563EB，60/30/10
- 类型 14px × 1.25 → 11/12/14/16/18/22/28/44；层级 = 字号+字重+颜色 三者一起
- 间距 8px 网格 s1–s10（4→80），组内紧、组间松（节奏不均）
- 圆角三档 r-ctl 6 / r-card 10 / r-pill 999（同心 = 内层 + padding）
- 深度用三档层叠透明阴影取代硬边框；输入框底色比周围更深（内嵌感）
- 动效 ≤160ms、抽屉 240ms、cubic-bezier(.23,1,.32,1)、只动 transform/opacity、:active 缩 0.975、不用 transition:all

界面：
- 首页 hero（eyebrow + 44px 标题 + lede + 主/次 CTA + 真实统计条：题数/批次/工具数/可用分区）
- 焦点卡改为通栏 hero 卡（左侧图标+名称+能力 chips，右侧「进入分析」），规划中分区降级为灰色卡片一排
- 新增「它是怎么工作的」三步（真实流程，不是填充文案）
- 设置改为右侧滑入抽屉（含遮罩、Esc 关闭、?settings=1 深链）
- 元件全部重做：分段式页签、卡片、药丸标签、控制台（带标题栏+步骤列号）、表格、成果库列表、空状态、内联 SVG 图标（替代 emoji）
- 响应式：≤920 单列、≤760 收顶栏、长路径 overflow-wrap:anywhere

修 2 个真 bug（单元测试全绿时依然存在，靠截图自查发现）：
- button{align-items:center} 泄漏进纵向 flex 卡片 → 卡片内容整体横向居中（显式 align-items:stretch）
- CSS 里设了 display 会让 hidden 属性失效（.work{display:grid} 覆盖 [hidden]{display:none}）
  → 两个页签面板同时露出（全局 [hidden]{display:none !important} 并写进测试）

澄清一个假 bug：
- 曾以为窄屏横向溢出并改了三轮 CSS，截图字节数完全一致（信号）→ 加 ?diag=1 覆盖层量出
  「无头 Edge 把窗口宽度钳到最小 ≈496 CSS px，而截图仍按 414 裁」→ 是裁剪假象，不是布局 bug。
  已把该陷阱与「先量再改」的做法写进经验库；窄屏验证改用 --window-size=500。
